# 🌾 AeroGrano Rural

**Innovación circular para una poscosecha más eficiente.**

AeroGrano Rural es un proyecto académico que propone aprovechar **motores recuperados** para facilitar la limpieza de granos como frijol, arroz y maíz, mediante aire, zaranda y gravedad. Está pensado para explorar alternativas accesibles para pequeños productores rurales.

Este repositorio contiene su **dashboard interactivo de análisis y sostenibilidad**, con dos perspectivas:

- **Escenario A | Antes y después:** compara la limpieza manual con el uso de AeroGrano.
- **Escenario B | Evolución mensual:** muestra registros, productividad y tendencias a lo largo del tiempo.

El sitio también permite registrar operaciones, importar y exportar datos en Excel, generar presentaciones PowerPoint y realizar una visita guiada.

### 🌱 Nuestro enfoque

Economía circular, innovación apropiada y aprovechamiento de recursos, en relación con los **ODS 2, 9 y 12**.

### 💻 Tecnologías

`HTML` · `CSS` · `JavaScript` · `IndexedDB`


> **Nota:** Es un prototipo académico. Los datos simulados se utilizan para demostrar el funcionamiento del dashboard y no representan resultados de pruebas reales.
